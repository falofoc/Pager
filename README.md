# دورك (Dorak) — دورك يصلك

منتج SaaS يحلّ محلّ أجهزة النداء (Pagers) في المقاهي والمطاعم، ويحوّل دقائق الانتظار إلى وعد صادق بالوقت، ونداء لا يُفوَّت، وطلب يردّ عليك، وبيانات تشغيل حقيقية لصاحب المقهى. بلا تطبيق، بلا تسجيل، بلا أجهزة.

## لغة المنتج

عربية معاصرة محايدة تصلح لكل الأسواق العربية، وإنجليزية بسيطة. لا لهجة، لا عبارات عامية، لا تعجّب متكرر، لا مبالغة. القواعد الكاملة في قسم العلامة داخل الـBlueprint.

## الفكرة في جملة

> دورك يحوّل كل طلب إلى وعد حيّ بين المقهى والعميل: العميل يعرف دائمًا ماذا يحدث ومتى، والمقهى يعرف دائمًا أن العميل سمع النداء.
