# دورك — التطبيق

نظام نداء وانتظار بلا أجهزة وبلا تطبيق: صفحة العميل، لوحة الموظف، شاشة الأرقام، ولوحة المدير، في تطبيق Next.js واحد.

## التشغيل المحلي

```bash
cd web
npm install
npm run setup      # ينشئ قاعدة SQLite ويضيف بيانات تجريبية (4 أسابيع من الطلبات)
npm run dev        # http://localhost:3000
```

| ماذا | أين | الدخول |
|---|---|---|
| لوحة المدير | `/login` | `demo@dorak.app` / `dorak1234` |
| لوحة الموظف | `/s` | رمز الربط `DEMO01` |
| صفحة العميل | `/c/sidra` | بلا تسجيل |
| شاشة الأرقام | `/tv/sidra?key=demo-tv-key` | مفتاح الشاشة |
| منشأة جديدة | `/start` | تسجيل ذاتي |

للإنتاج محليًا: `npm run build && npm start`.

## المفاتيح الخارجية

لا يحتاج التشغيل أي مفتاح. الصفحة الحيّة، وإشعارات الجوال (VAPID يُولَّد تلقائيًا)، وتنبيه الموظف، وشاشة الأرقام تعمل فورًا.

كل ما يحتاج مفتاحًا يُضاف من **لوحة المدير ← التكاملات والمفاتيح**، ويُحفظ مشفّرًا لكل منشأة:

- **الرسائل النصية:** Unifonic أو Twilio، مع رابط الرسائل الواردة الجاهز للصق في لوحة المزوّد.
- **واتساب:** WhatsApp Cloud API (Access Token، Phone Number ID، الرقم التجاري)، مع Callback URL و Verify Token جاهزين للصق في Meta.
- **تقييم Google:** معرّف المكان (Place ID) لكل فرع من إعدادات الفرع.

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | `file:./dev.db` محليًا. للإنتاج على PostgreSQL غيّر `provider` في `prisma/schema.prisma` |
| `APP_SECRET` | مفتاح تشفير الأسرار. إن تُرك فارغًا يُولَّد في `.data/app-secret`. **في الإنتاج عيّنه صراحة** |
| `APP_URL` | العنوان العام (لرموز QR وروابط الـwebhooks). إن تُرك فارغًا يُستنتج من الطلب |

## البنية

```
src/
  core/        منطق نقي مختبر: الأرقام المقاومة للخطأ، الوقت المتوقع، الولاء، سلّم النداء، التوصيات
  server/      الخدمات: الطلبات، البث اللحظي (SSE)، المجدول، الإشعارات، التحليلات، المصادقة، التشفير
  app/
    c/[slug]   ربط العميل بطلبه (قائمة + لوحة أرقام)
    o/[token]  صفحة الطلب الحيّة: انتظار، زخرفة، نداء، تقييم، Google، بطاقة الأختام، بلا اتصال
    s/         لوحة الموظف وربط الجهاز
    tv/[slug]  شاشة الأرقام
    m/         لوحة المدير: اليوم، الإعدادات، التكاملات، الطباعة، الفروع
    api/       واجهات العميل والموظف والشاشة والـwebhooks
public/sw.js   إشعارات الويب والعمل بلا اتصال
```

- **البث اللحظي والمجدول** يعملان داخل عملية الخادم نفسها (`instrumentation.ts`)، فلا حاجة لـ Redis في نسخة واحدة. للتوسع إلى عدة نسخ يُستبدل `server/hub.ts` بـ Redis Pub/Sub، ويبقى المجدول في نسخة واحدة أو يُنقل إلى طابور مهام.
- **كل طلب يترك سجل أحداث** (`OrderEvent`) ومحاولات نداء (`NotificationAttempt`)، ومنها تُحسب تقارير المدير.
